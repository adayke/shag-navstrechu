# Шаг навстречу

Прототип приложения для педагога-психолога по методическому пособию «Шаг навстречу. Развитие эмоциональной сферы и коммуникативных навыков у младших школьников с ООП» (автор-составитель А. А. Абайканова, 2025).

**Сайт:** https://adayke.github.io/shag-navstrechu/

## Что есть

- **Занятия** — 136 занятий из рабочих тетрадей 1–4 классов, фильтр по классу и блоку, поиск.
- **Проведение занятия** — 5 этапов встречи с тихим таймером.
- **Наблюдение** — шкала 0–3 или «не оценивалось», способ ответа, где проявилось, следующий шаг.
- **Дети** — цели на цикл, график динамики, отчёт для печати.
- **Режим для ребёнка** — колесо настроения, сила чувства, карточки «Стоп / Пауза / Помоги», таймер паузы.
- **Языки** — русский и казахский (переключатель в меню). Казахский перевод нужно вычитать носителю языка.

Данные демо и хранятся только в браузере (localStorage). Сервера и входа нет.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` → папка `dist/`.

## Структура

```
src/
  App.jsx              меню и выбор страницы
  pages/               страницы
  components/          график, режим для ребёнка, общие элементы
  i18n/ru.js, kk.js    тексты интерфейса
  data/lessons.*.json  занятия из тетрадей (ru / kk)
  data/demo.js         демо-дети и наблюдения
  state/               данные (store) и роутер
```

Публикация: при пуше в `main` GitHub Actions собирает проект и выкладывает на GitHub Pages (`.github/workflows/deploy.yml`).
